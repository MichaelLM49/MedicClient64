# This repository contains the files necessary to run the demo version of the free Medic Nuclear Medicine Image Processing and Documentation system.
> Download the .zip file and after unpack copy the files and directories to the c:\medic directory.
>
> Open a command window (you must have administrative privileges). Goto the c:\medic  
directory and install the Firebird ver, 2.1.7 database. 
>
> To start the Medic client application goto the c:\medic\bin64 and doubleclick the MedicClient64.exe file.
>
> If Windows Defender blocks the excecution select "Run anyway".
>
> For further information see the "Medic Processing Users Manual" document in the c:\medic directory  
or the website www.gamma-soft.dk.
> If you have further questions please send a mail to michael@gamma-soft.dk
